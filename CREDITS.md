# Credits

FNV was rebuilt function by function by a community of contributors, coordinated on
[fnvdecomp.com](https://fnvdecomp.com). These contributors chose to be named; the numbers are the functions and bytes of verified
matches each of them handed in (as of 2026-11-02). A function reopened for rework and matched again counts for both
the first matcher and the reworker. 8 further contributors took part anonymously.

The rest of the code was matched by the project's own tooling.
